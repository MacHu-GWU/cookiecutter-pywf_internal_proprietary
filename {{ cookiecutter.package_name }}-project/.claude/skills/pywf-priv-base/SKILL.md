The conventions of the pywf internal proprietary Python library template, shared by every `pywf-priv-*` skill. Such a library is closed source: its releases go to a private AWS CodeArtifact repository instead of PyPI, CI reaches AWS through OIDC, there is no coverage service, docs are hosted on Cloudflare Pages only when a library needs it, and maintenance knowledge lives in a `maintain-<package_name>` skill family instead of docs pages. `<package_name>` is the import package directory: snake_case, equal to `[project].name` in `pyproject.toml`.
