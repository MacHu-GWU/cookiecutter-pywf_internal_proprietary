# Repository Layout

---

## 1. Tree

```text
<package_name>-project/
├── <package_name>/            # the importable package
├── tests/                     # unit tests, mirroring <package_name>/
├── tests_int/                 # optional: integration tests against real external services
├── tests_load/                # optional: load tests
├── docs/source/               # Sphinx source
├── .mise/tasks/               # scripts behind mise tasks, including codeartifact-env.sh
├── .claude/                   # Claude Code settings, launch.json (docs preview server), and skills:
│   └── skills/                #   pywf-priv-* (template), pypi-<package_name> (API), <maintain_prefix>-* (maintenance)
├── .github/workflows/main.yml # CI
├── pyproject.toml             # metadata, dependencies, tool config (ruff, pytest)
├── mise.toml                  # tools, tasks, env vars
├── uv.lock                    # generated
├── requirements*.txt          # generated by `mise run export`
├── .coveragerc                # coverage config (local only: no coverage service)
├── README.rst                 # short: what, install from CodeArtifact, the API skill, links
├── release-history.rst        # changelog
├── AUTHORS.rst / LICENSE.txt
└── CLAUDE.md                  # project guide for AI: a project block and a template block
```

---

## 2. Generated outputs

| Path | Committed? |
| :--- | :--- |
| `uv.lock`, `requirements*.txt` | yes |
| `docs/source/api/` | yes, and regenerated on every docs build |
| `htmlcov/`, `docs/build/`, `dist/`, `build/`, `tmp/`, `*.egg-info`, `.wrangler/` | no |

Never edit a generated file by hand. Change its source, and regenerate it.

---

## 3. `CLAUDE.md`

- **The project block** holds facts about this library. Edit it freely.
- **The template block,** between the `<!-- BEGIN pywf-priv template block` and `<!-- END pywf-priv template block -->` markers, is shared by every template repo and replaced as a whole on a template upgrade. Do not edit it per repo.
